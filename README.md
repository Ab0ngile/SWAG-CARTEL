## Project Overview

SWAG CARTEL is a proposed local sneaker retail website designed
to provide customers with information about the organisation, its
sneaker products and available services.

## Website Goals and Objectives

- Create a professional online presence.
- Display sneaker products.
- Provide information about the organisation.
- Allow customers to make enquiries.
- Provide contact information.
- Create an easy-to-use navigation system.

## Key Features and Functionality

- Homepage
- About Us page
- Sneakers/Products page
- Services page
- Enquiry page
- Contact page
- Navigation menu
- Responsive design
- Product information
- Customer enquiry form
